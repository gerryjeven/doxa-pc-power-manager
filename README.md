# Doxa PC Power Manager

Atur **processor power management** di Windows dengan tampilan modern: batasi kecepatan CPU agar lebih dingin dan
hemat baterai, atau buka penuh untuk performa maksimal, dengan satu klik.

*Control your CPU power settings on Windows with a modern UI: keep your PC cool and quiet, save battery,
or unlock full performance in one click.*

## Unduh

➡️ **[Unduh versi terbaru (DoxaPCPowerManager.exe)](https://github.com/gerryjeven/doxa-pc-power-manager/releases/latest)**

Satu file, tanpa instalasi tambahan. Buka file-nya, setujui permintaan administrator (UAC), lalu klik
**Install ke PC ini** bila ingin memasangnya di Start Menu.

> Saat pertama dibuka, Windows SmartScreen mungkin menampilkan peringatan karena aplikasi belum ditandatangani
> digital. Pilih **More info → Run anyway**.

## Fitur

- **Preset satu klik:** Hemat Daya, Seimbang, Performa
- **Setelan lengkap:** Minimum/Maximum Processor State, Turbo Boost, Energy Performance Preference, Cooling Policy,
  dan pilihan power plan, terpisah untuk saat dicolok listrik dan saat memakai baterai
- **Monitor langsung:** pemakaian CPU, frekuensi, dan status baterai
- **Menyesuaikan perangkat:** laptop, desktop, maupun server; setelan yang tidak didukung otomatis disembunyikan
- **7 bahasa:** Bahasa Indonesia, English, 中文, 한국어, 日本語, ไทย, العربية
- **Tema gelap & terang**
- **Update otomatis:** aplikasi memberi tahu saat versi baru tersedia dan memasangnya sendiri

## Kebutuhan sistem

- Windows 10 atau 11 (64-bit)
- Microsoft Edge atau Google Chrome (dipakai untuk menampilkan jendela aplikasi)
